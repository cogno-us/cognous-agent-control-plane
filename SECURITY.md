# Security Policy

## Reporting a vulnerability

Please report security issues through the repository's private vulnerability
reporting feature if available, or contact the maintainers through the
organization profile.

Do **not** report security vulnerabilities via public GitHub issues.

## Scope

This project is a reference implementation.  Security reports related to the
policy gate logic, data integrity of run records, and any unintended network
calls or credential exposure are in scope.

## Response

We aim to acknowledge reports within 5 business days and provide a
resolution or mitigation plan within 30 days for confirmed vulnerabilities.
